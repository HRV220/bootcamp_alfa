# Схемы

Редактируемые объекты схем находятся на слайдах 4 и 5 итоговой PPTX. Mermaid-файлы рядом — отдельные исходники логической ER-модели и целевой архитектуры. Это описание проектных связей, а не доказательство внедрения.

`match_players` связывается с покупкой по `match_id` и `account_id = steam_account_id` только при ровно одном совпадении. Неоднозначные/отсутствующие связи не восстанавливаются догадками. CSV не имеет подтверждённого общего периода с SQL-срезом. ML score, peer history и контроль пока проектные.
