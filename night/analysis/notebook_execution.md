# Как воспроизвести notebook

Из корня проекта выполните:

```powershell
python night/analysis/profile_smurf.py
python night/analysis/build_analysis_notebook.py
```

Вторая команда создаёт `analysis_review.ipynb` и исполняет его кодовые клетки последовательно
через CPython `exec` в общем пространстве имён. Используется только стандартная библиотека.
Каждый stdout реально захватывается в `outputs`, клетки получают `execution_count`.
Это исполнение Python-кода, а не запуск ядра Jupyter. Метаданные notebook явно фиксируют метод.

`notebook_execution.json` содержит UTC-время, версию Python, статус каждой клетки, stdout,
SHA-256 её кода, ошибки, итоговый код результата и контрольную сумму notebook/источника.
При ошибке исполнение прекращается и процесс возвращает код 1. При успехе возвращает 0.

Можно также открыть notebook в Jupyter и выполнить все клетки из директории внутри проекта.
Первый блок повторно читает исходный CSV, последующие пересчитывают показатели, проверяют
формулы и строят таблицу шести аккаунтов. Последняя кодовая клетка сверяет показатели
с ранее созданным `smurf_profile.json` и подтверждает неизменность источника.

Notebook не обучает ML-модель и не оценивает качество детектора. Его результат — профиль
предоставленной выборки с явными ограничениями. Исходные файлы в `task/` не изменяются.
