# Актуальная версия по всем трём кейсам

Основные файлы:

- `output/Dota2_All_Cases_v2.pptx` — презентация, 15 слайдов.
- `output/Dota2_All_Cases_v2.pdf` — версия для просмотра.
- `output/Текст_защиты.md` — источники и пояснения к слайдам.
- `ОТЧЕТ.md` — что изменилось, подтверждённые результаты и оставшиеся проблемы.
- `research/case1.md`, `case2.md`, `case3.md` — подробный разбор каждого кейса.
- `research/final_review.md` — независимая проверка.
- `qa/validation_summary.json` — машинные проверки и неизменность исходных материалов.

Главное отличие от первой версии: включены реальные результаты SQL/Superset, эксперименты CatBoost/SHAP и LLM-прототип. Проверка не заменяет повторного исполнения кейсов: обнаруженные ошибки и ограничения перечислены в отчёте.
