README — главный источник информации о проекте. Общие требования и справочные материалы находятся в `requirements/`, выбранные кейсы — в `task/selected_cases.md`, материалы кейса про Доминатор — в `task/case1/`.

**Старт:** 12.11.2026 · **Статус:** исследование и проектирование · **Фокус:** Доминатор и винрейт, ML №18, LLM №24.

## Структура проекта

- `requirements/` — общие требования, описание источников, критерии оценки и команда.
- `requirements/examples/` — учебные ноутбуки, общие для проекта.

- `task/case1/` — паспорт кейса и модель данных со встроенной ER-диаграммой.


## Выбранные кейсы

| Направление | Кейс | Статус |
|---|---|---|
| SQL / аналитика | **Время покупки Доминатора → винрейт** | Сравнение первой покупки до 8 минут включительно и после 8 минут; метод проверки ещё не согласован |
| ML №18 | **Обнаружение смурфов** | Поиск аномальных профилей относительно peers с учётом роли и уровня матча; аномальность не доказывает смурфинг |
| LLM №24 | **Саммари матча** | Структурированное описание из проверенных фактов; контроль полноты, выдуманных событий и формата |

**Гипотеза кейса 1:** среди покупателей Доминатора винрейт команды при первой покупке до 8 минут включительно выше, чем при покупке после 8 минут. Порог основан на заданном пользователем ориентире среднего времени сборки; фактическое среднее ещё не рассчитано. Метрика — разница винрейтов в процентных пунктах. Цели, гипотезы и ограничения всех трёх кейсов: [selected_cases.md](task/selected_cases.md).

## Источники и архитектура

Подтверждённые ниже источники исследуются для кейса 1. Наборы данных и необходимые поля для ML №18 и LLM №24 предстоит определить отдельно.

- **PostgreSQL:** схема `dota`, прежде всего `matches`, `match_players`, `items`, `heroes`.
- **MongoDB:** `dota_events`, коллекция `purchase_events`.
- **Ключи:** `match_id`; `account_id` в PostgreSQL ↔ `steam_account_id` в событиях.
- **Целевой процесс:** PostgreSQL/MongoDB → Airflow → Spark → Iceberg/MinIO (RAW/STAGE/MART) → Trino → Superset.
- **Риск:** в документации указан retention исходных данных ~4 часа; долговременное хранение в Iceberg нужно проверить.
- **По сообщению пользователя подтверждены четыре RAW-таблицы и ID Доминатора (164). Проверки качества, единицы времени и согласованности ключей ещё не завершены; ETL предстоит спроектировать заново.**
