## Источники и архитектура

- **PostgreSQL:** схема `dota`, прежде всего `matches`, `match_players`, `items`, `heroes`.
- **MongoDB:** `dota_events`, коллекция `purchase_events`.
- **Ключи:** `match_id`; `account_id` в PostgreSQL ↔ `steam_account_id` в событиях.
- **Целевой процесс:** PostgreSQL/MongoDB → Airflow → Spark → Iceberg/MinIO (RAW/STAGE/MART) → Trino → Superset.
- **Риск:** в документации указан retention исходных данных ~4 часа; долговременное хранение в Iceberg нужно проверить.
- **По сообщению пользователя подтверждены четыре RAW-таблицы и ID Доминатора (164). Проверки качества, единицы времени и согласованности ключей ещё не завершены; результаты ETL не проверены.**

[Полная схема источников](requirements/Источники.%20Описание%20полей%20таблиц.md) · [Подтверждённые RAW-таблицы и задача DQ](task/case1/source_profiling.md).
