## Источники и архитектура

- **PostgreSQL:** схема `dota`, таблицы `matches`, `match_players`, `players`, `items`, `heroes`.
- **MongoDB:** `dota_events`, для наших кейсов прежде всего `purchase_events`, `tower_damage_events`, `tower_death_events`, `kill_events`, `buyback_events`.
- **Ключи:** `match_id`; `account_id` в PostgreSQL ↔ `steam_account_id` в событиях.
- **Целевой процесс:** PostgreSQL/MongoDB → Airflow → Spark → Iceberg/MinIO (RAW/STAGE/MART) → Trino → Superset.
- **Риск:** в документации указан retention исходных данных ~4 часа; долговременное хранение в Iceberg нужно проверить.
- **Доступность данных и результаты ETL ещё не проверены.**

[Полная схема источников](docs/Источники.%20Описание%20полей%20таблиц.md) · [Выводы только по выбранным кейсам](docs/Источники_ключевые_выводы.md).
