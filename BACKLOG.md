# Бэклог проекта «Аналитика Dota 2»

**Статус:** все задачи выполнены.

**Цель проекта:** подготовить данные и аналитическое решение для трёх кейсов: связь времени покупки Доминатора с винрейтом, обнаружение подозрительно сильных выступлений игроков и генерация текстового обзора матча.

## Эпик E05. ML — обнаружение смурфов

**Цель:** выделить подозрительно сильные выступления и объяснить прогноз модели.

- [x] **E05-01. Подготовить входные данные ML.** — **DE, PA**  
  Организовать загрузку статистики игроков, обработку пропусков и подготовку инвентаря и числовых показателей.
- [x] **E05-02. Рассчитать признаки выступления.** — **PA, DE**  
  Подготовить GPM, XPM, KDA, урон и добивания в минуту, ранговую группу и позицию по фарму внутри команды.
- [x] **E05-03. Разработать автоматическую разметку.** — **PA, DE**  
  Рассчитать отклонение от сопоставимых игроков и сформировать метку необычно сильного выступления.
- [x] **E05-04. Подготовить выборки и базовую модель.** — **PA, DE**  
  Разделить данные по аккаунтам на train, validation и test, подготовить CatBoost и выбор порога по validation.
- [x] **E05-05. Провести подбор параметров и сравнение моделей.** — **PA**

- [x] **E05-06. Подготовить объяснения прогнозов.** — **PA**  
  Построить SHAP-графики общей важности и влияния признаков, разобрать отдельные прогнозы.

**Результат эпика:** подготовлены ML-ноутбук, результаты экспериментов и объяснения модели. Метрики рассчитаны по автоматической разметке.
