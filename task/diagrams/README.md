# ER-диаграммы трёх кейсов

Основной документ с четырьмя встроенными диаграммами, расшифровкой сущностей и ограничениями: [общая модель данных](../data_model.md).

Для кейса 2 также подготовлены две версии в его папке: [логическая модель ML-процесса](../case2/er_logical.md) и [фактические таблицы и CSV](../case2/er_physical.md).

| Исходник Mermaid | Содержание |
|---|---|
| [common.mmd](common.mmd) | Общее ядро и результаты трёх кейсов |
| [case1.mmd](case1.mmd) | Покупки Доминатора и детальная витрина |
| [case2.mmd](case2.mmd) | CSV кандидатов, ML-признаки, эталоны peers и прогнозы |
| [case3.mmd](case3.mmd) | События матча, вход LLM, описания и обзор |

Mermaid-блоки в основном Markdown-документе отображаются в просмотрщиках с поддержкой Mermaid, например в GitHub. `.mmd` — отдельные редактируемые исходники тех же диаграмм. После изменения `.mmd` нужно обновить соответствующий блок в документе.

Первоначальная диаграмма кейса 1 в [case1/data_model.md](../case1/data_model.md) сохранена без изменений. Новая версия дополняет её детальной MART-витриной из текущего SQL и показывает возможные отсутствующие связи.
