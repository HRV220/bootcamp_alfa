## ML №16 — Обнаружение смурф-аккаунтов

## 16. Обнаружение смурф-аккаунтов (аномалии)

**Тип:** spark + ml (обнаружение аномалий / бинкаунт)

**Данные:**

- `match_players` — усреднённая стата по `account_id` (KDA, GPM, XPM, win rate)
- `players` / `raw_players` — никнеймы
- `matches` — количество матчей, `duration`

**Гипотеза:** смурф-аккаунты отличаются аномально высокой статистикой (KDA > 5, GPM > 700, win rate > 65%) при малом количестве игр, часто с подозрительными никнеймами (набор символов)

**Метод:**

1. Агрегировать статистику по `account_id`:
   - Средний KDA
   - Средний GPM/XPM
   - Win rate
   - Количество матчей
   - Средняя длительность матчей
   - Список героев
2. **Isolation Forest** или **LOF (Local Outlier Factor)** для поиска аномалий
3. Дополнительно: частота смены ника (по `raw_players.loaded_at`)

```python
from pyspark.ml.feature import VectorAssembler, StandardScaler
from pyspark.ml.clustering import KMeans

player_stats = spark.sql("""
  select mp.account_id,
    avg((mp.kills + mp.assists) / greatest(mp.deaths, 1)) as avg_kda,
    avg(mp.gold_per_min) as avg_gpm,
    avg(mp.xp_per_min) as avg_xpm,
    avg(case when mp.win then 1.0 else 0.0 end) as win_rate,
    count(*) as matches_played,
    count(distinct mp.hero_id) as unique_heroes
  from iceberg.raw.pg__match_players mp
  group by mp.account_id
  having count(*) >= 5
""")

# Isolation Forest
from pyspark.ml.classification import RandomForestClassifier

)
scaler = StandardScaler(inputCol="features", outputCol="scaled")
```

## LLM №22 — Саммари матчей

## 22. Генерация саммари матча на естественном языке (LLM API)

**Тип:** llm (openai / llama / любой llm) + spark

**Данные:**

- Структурированные данные по одному матчу:
  - `matches` — победитель, длительность, game_mode
  - `match_players` — стата каждого игрока
  - `kill_events` — убийства (количество)
  - `tower_damage_events` — башни (количество, порядок)
  - `cs_events` (npcId=133) — Рошан (был ли, когда)
  - `gold_events` — максимальный разрыв по золоту
  - `streak_events` — максимальная серия убийств
  - `purchase_events` — ключевые предметы
  - `ability_learn_events` — порядок прокачки
  - `heal_events` / `hero_damage_events` — статистика урона/лечения
  - `rune_events` — контроль рун

**Гипотеза:** LLM может написать связное текстовое описание матча по его структурированным данным — как репортаж.

**Применение:**

- Автоматическая генерация хайлайтов для сайта/дашборда
- Саммари для каждого матча в enrichment pipeline
- Поиск самых интересных матчей (по тексту саммари можно искать "огромный камбэк" или "полный разгром")

**Метод:**

1. Для матча собрать JSON с ключевыми метриками
2. Отправить в LLM с промптом
3. Получить текст на 2-3 предложения с описанием матча
4. Сохранить результат рядом с данными в Iceberg или PG

```python
def build_match_summary(match_id: int) -> str:
    # Выбираем данные по матчу
    match = spark.sql(f"""
      select
        m.match_id,
        m.duration,
        m.radiant_win,
        (select count(*) from iceberg.raw.mongo__kill_events ke
         where ke.match_id = m.match_id) as total_kills,
        (select count(*) from iceberg.raw.mongo__tower_damage_events tde
         where tde.match_id = m.match_id) as tower_hits,
        (select min(time) from iceberg.raw.mongo__cs_events ce
         where ce.match_id = m.match_id and ce.npc_id = 133) as roshan_time,
        (select max(g.value) from iceberg.raw.mongo__gold_events g
         where g.match_id = m.match_id) as max_gold_lead
      from iceberg.raw.pg__matches m
      where m.match_id = {match_id}
    """).toPandas().iloc[0]

    # Топ игроков
    players = spark.sql(f"""
      select h.localized_name, mp.kills, mp.deaths, mp.assists,
        mp.gold_per_min, mp.hero_damage, mp.hero_healing
      from iceberg.raw.pg__match_players mp
      join iceberg.raw.pg__heroes h on mp.hero_id = h.hero_id
      where mp.match_id = {match_id}
      order by mp.hero_damage desc
    """).toPandas()

    prompt = f"""
Match ID: {match['match_id']}
Duration: {match['duration']}s
Winner: {'Radiant' if match['radiant_win'] else 'Dire'}
Total kills: {match['total_kills']}
First Roshan: {f'{match["roshan_time"]}s' if match['roshan_time'] else 'not killed'}
Tower hits: {match['tower_hits']}
Max gold lead: {match['max_gold_lead']}

Players:
{players.to_string(index=False)}

Write a 2-3 sentence match summary in Russian, describing the key moments.
If there was a comeback (team was behind but won), highlight it.
"""

    resp = requests.post(
        API_URL,
        headers={"Authorization": "Bearer $OPENAI_KEY"},
        json={
            "model": "gpt-4o-mini",
            "messages": [{"role": "user", "content": prompt}],
            "temperature": 0.3
        }
    )
    return resp.json()["choices"][0]["message"]["content"]

# Пример: "Radiant победил за 34 минуты. Ключевой момент — убийство Рошана на 22 минуте,
# после которого Dire взяли две башни и получили золотой разрыв в 8k.
# Shadow Fiend закончил с 15/3/10 и 800 GPM."
```
