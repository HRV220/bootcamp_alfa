# Выбранные кейсы команды

Дата фиксации: **12 ноября 2026 года**. Решение команды — **SQL №13, ML №16, LLM №22**. Нумерация соответствует исходному перечню пользователя, а не номерам учебных ноутбуков.

## SQL №13 — Ключевые предметы → пуш

- **Идея:** исследовать связь покупок ключевых предметов с последующим уроном по башням и темпом пуша.
- **Потенциальные источники:** MongoDB `purchase_events` (`match_id`, `steam_account_id`, `itemId`, `time`), `tower_damage_events` (`match_id`, `steam_account_id`, `time`, `damage`), `tower_death_events` (`match_id`, `time`); PostgreSQL `items`, `match_players`, `matches`.
- **Основной риск:** корреляция не равна причинному эффекту; сравнивать события строго после покупки, учитывать длительность и состояние матча.
- **Статус:** выбран; гипотезы, критерии отбора ключевых предметов, итоговые метрики и ETL ещё не утверждены.

## ML №16 — Обнаружение смурф-аккаунтов

- **Идея:** выявлять игроков с признаками игры существенно выше уровня аккаунта.
- **Потенциальные источники:** PostgreSQL `players` (`account_id`), `match_players` (`match_id`, `account_id`, `rank`, `kills`, `deaths`, `assists`, `gold_per_min`, `xp_per_min`, `hero_damage`, `win`), `matches` (метаданные матчей).
- **Основной риск:** документированная схема **не содержит подтверждённой метки smurf/not smurf**. Нужно отдельно определить способ разметки, подход (supervised vs anomaly detection), надёжность данных по истории аккаунта, валидность оценки.
- **Статус:** выбран; схема обучения и метрики не утверждены.

## LLM №22 — Саммари матчей на естественном языке

- **Идея:** генерировать краткое фактическое текстовое описание матча по подготовленным данным.
- **Потенциальные источники:** PostgreSQL `matches`, `match_players`, `heroes` и релевантные события MongoDB (`kill_events`, `tower_death_events`, `buyback_events`, другие при необходимости).
- **Основной риск:** выдуманные факты в ответах LLM; требуются детерминированная сборка фактов, ограничения промпта и оценка достоверности саммари.
- **Статус:** выбран; формат саммари, язык, модель и критерии качества ещё не утверждены.

## Следующая задача первого дня

Для каждого из трёх выбранных кейсов сформулировать **бизнес-вопрос, проверяемые гипотезы, метрики, необходимые поля и метод проверки**, далее проверить качество и полноту источников.
