# Выбранный кейс: время покупки Доминатора и винрейт

Дата фиксации: **12 ноября 2026 года**. По решению пользователя в работе **только один кейс** — связь времени покупки Helm of the Dominator с вероятностью победы в матче. Прежние варианты исключены из текущего объёма.

**Категория:** SQL / аналитика. Подготовка данных и расчёт метрик — SQL/Spark; статистическая проверка — Python/Jupyter. ML и LLM в текущий объём не входят.

Тема и основная гипотеза зафиксированы. Границы групп таймингов, метод проверки и достаточность данных ещё предстоит согласовать. Наличие связи не доказывает причинного эффекта.

## Тема и гипотеза

- **Тема:** связь времени покупки Helm of the Dominator с вероятностью победы в матче Dota 2.
- **Бизнес-вопрос:** связан ли более ранний тайминг покупки Доминатора с более высоким винрейтом команды покупателя?
- **Цель:** сравнить долю побед при разных таймингах покупки Доминатора с учётом героя покупателя и контекста матча.
- **H₀:** время покупки Доминатора не связано с вероятностью победы команды покупателя.
- **H₁:** среди игроков, купивших Доминатор, более ранняя покупка связана с более высоким винрейтом их команды.
- **Предварительные метрики:** винрейт по группам времени покупки, разница винрейтов в процентных пунктах, доверительные интервалы, число покупателей и уникальных матчей в каждой группе.
- **Единица анализа:** первая покупка Доминатора игроком в матче. Повторные покупки того же игрока не создают новых наблюдений; несколько покупателей из одного матча не считаются независимыми наблюдениями.
- **Потенциальные источники:** PostgreSQL `items`, `heroes`, `match_players`, `matches`; MongoDB `purchase_events`.
- **До анализа:** определить ID предмета по справочнику, проверить время первой покупки, согласовать границы групп «ранняя / средняя / поздняя» до проверки гипотезы, выбрать героев и правила сопоставления по рангу, режиму и типу лобби. Проверить согласованность `win` с `is_radiant` и `radiant_win`.
- **Ограничения:** ранняя покупка может отражать уже существующее преимущество команды. Поздняя покупка возможна только в достаточно длинном матче, поэтому необходимо учитывать различия в составе сравниваемых выборок. Исследование среди покупателей не оценивает пользу покупки относительно игры без Доминатора и не доказывает причинного влияния предмета на победу.
- **Статус:** единственный выбранный кейс проекта; тема и основная гипотеза зафиксированы пользователем.
