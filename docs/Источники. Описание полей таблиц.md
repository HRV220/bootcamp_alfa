# Описание полей таблиц и коллекций

## PostgreSQL — схема `dota`

---

### Таблица `heroes`

Справочник героев Dota 2.

| Поле | Тип PG | Iceberg | Описание |
|---|---|---|---|
| `hero_id` | INTEGER PK | INT | Уникальный ID героя (Valve) |
| `name` | TEXT | STRING | Internal name (например `npc_dota_hero_antimage`) |
| `localized_name` | TEXT | STRING | Отображаемое имя (например `Anti-Mage`) |
| `primary_attr` | TEXT | STRING | Основной атрибут: `str`, `agi`, `int`, `all` |
| `attack_type` | TEXT | STRING | Тип атаки: `Melee` или `Ranged` |
| `roles` | array<string> | ARRAY<STRING> | Список ролей героя (например `["Carry", "Escape"]`) |

---

| `components` | array<string> | ARRAY<STRING> | Список short name компонентов (null если нет) |

### Таблица `cleanup_runs`

Журнал запусков очистки (retention). Запускается каждые 4 часа,
удаляет матчи старше 4 часов (по `loaded_at`) из PostgreSQL вместе с их
`match_players`, затем осиротевших `players`, соответствующие
события из MongoDB, после чего `compact` MongoDB.

| Поле | Тип PG | Iceberg | Описание |
|---|---|---|---|
| `run_id` | SERIAL PK | INT | Уникальный ID запуска |
| `started_at` | TIMESTAMPTZ | TIMESTAMP | Время начала |
| `finished_at` | TIMESTAMPTZ | TIMESTAMP | Время завершения |
| `duration_sec` | REAL | FLOAT | Длительность (сек) |
| `status` | TEXT | STRING | Статус: `running`, `success`, `failed` |
| `cutoff_dt` | TIMESTAMPTZ | TIMESTAMP | Время cutoff (удаляются данные до него) |
| `matches_deleted` | INTEGER | INT | Матчей удалено из PG |
| `players_deleted` | INTEGER | INT | Игроков удалено (включая orphans) |
| `mongodb_docs_deleted` | INTEGER | INT | Документов удалено из MongoDB |
| `mongodb_compacted` | BOOLEAN | BOOLEAN | Выполнен ли compact |
| `error_message` | TEXT | STRING | Ошибка (если статус = failed) |

## MongoDB — база `dota_events`

### Player-level коллекции

Каждый документ содержит общие поля:

| Поле | Тип Mongo | Iceberg | Описание |
|---|---|---|---|
| `_id` | ObjectId | STRING | Уникальный ID документа |
| `match_id` | long | LONG | ID матча |
| `steam_account_id` | long | LONG | Steam account ID игрока |
| `created_at` | datetime | TIMESTAMP | Время записи в UTC |

Далее указаны только поля, специфичные для каждого типа события.

### Match-level коллекции

Каждый документ содержит общие поля:

| Поле | Тип Mongo | Iceberg | Описание |
|---|---|---|---|
| `_id` | ObjectId | STRING | Уникальный ID документа |
| `match_id` | long | LONG | ID матча |
| `created_at` | datetime | TIMESTAMP | Время записи в UTC |

Эти коллекции хранят события уровня матча (варды, башни), не привязанные к конкретному игроку.
